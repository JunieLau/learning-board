# 学习板 / Learning Board

Junie Lau 的学习 moodboard：黑底网页，每块是一个想学的项目——上面是标志性画面，下面是标题和一段短说明。这一版可以把卡片自由摆在黑板上，拖动空白处移动视线，并缩放。按日期排开会重新排开，自己的标注还留着。位置和标注目前只写在这台浏览器里，还没有跨设备同步。

Live: https://junielau.github.io/learning-board/
