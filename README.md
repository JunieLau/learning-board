# 学习板 / Learning Board

Junie Lau 的学习 moodboard：黑底网页，每块是一个想学的项目——上面是标志性画面，下面是标题和一段短说明。卡片可以自由摆在黑板上，拖动空白处移动视线，并缩放。位置只写在这台浏览器里，没有跨设备同步。

每次内容更新发布之后，第一次打开会按原发布日期从新到旧重新排开全部卡片，包括以前在这台浏览器里保存过摆放和视角的情况。同一版里再拖动，仍留在这台浏览器。导出和导入备份还在。已经存过的标注不会被清掉，页面上也不再显示标注输入框。只给旧卡补链接不会改它的原发布日期。只有日期、没有钟点的条目，排在同一天里已经有钟点的条目之后。

维护规则：同一页上有两块板，目录在最上方。默认地址打开 Claude 学习板，`#openai` 或 `?board=openai` 打开 OpenAI 学习板。每块板各自按原发布日期从新到旧排，内容卡每行八张，说明卡单独占上面一行，不占内容位。没有脚本时，页面本身也是这个行列，不是五列，说明卡也不占格子。桌面第一次打开要把这一行放进窗口。两块板的位置和视角分开保存。官方页没有作品日期的项目，如果能找到作者在 X 的首发帖，就用首发帖时间；找不到的排在该板所有已知日期之后。OpenAI 板现在是 10 张独立创作者原帖和 7 张官方 Showcase，其中 5 张官方作品按作者首发帖时间排，2 张没有日期。GPT-6.2 Astra 的官方型号是 gpt-6.2-astra。作者写的 Ultra 不是官方型号名。

2026-11-25 全板复核：每张卡的「依据与限度」统一写原发布时间、作者自述的方法和工具（用过的和只拿来比较的分开写）、当天重新查的公开数据和核验时间、社区反馈抽样（含批评）、推广与利益关系，以及上板判断。每张卡的 `data-audit` 是 keep、borderline、recommend-removal 或 unverifiable。建议移除的卡还在板上，等 Junie 决定。逐张记录见 `records/cycles/2026-11-25-audit.json`。本地检查：`python3 tools/check_board.py`。
