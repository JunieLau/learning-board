# 学习板 / Learning Board

Junie Lau 的学习 moodboard：黑底网页，每块是一个想学的项目——上面是标志性画面，下面是标题和一段短说明。卡片可以自由摆在黑板上，拖动空白处移动视线，并缩放。位置只写在这台浏览器里，没有跨设备同步。

每次内容更新发布之后，第一次打开会按原发布日期从新到旧重新排开全部卡片，包括以前在这台浏览器里保存过摆放和视角的情况。同一版里再拖动，仍留在这台浏览器。导出和导入备份还在。已经存过的标注不会被清掉，页面上也不再显示标注输入框。只给旧卡补链接不会改它的原发布日期。只有日期、没有钟点的条目，排在同一天里已经有钟点的条目之后。

维护规则：默认排列和「按日期排开」都是内容卡每行正好八张，从新到旧、从左到右，排满再换下一行。开头的说明卡单独放在内容区上方，不占这八个位子。普通桌面第一次打开这一版时，要用视角把这一行八张同时放进窗口。手机上可以先框住能看清的几张，再靠拖动和缩放看其余的。以后的内容更新继续用每行八张，并且打开时桌面要看见这一整行。样式和脚本的地址要带上这一版的版本号。官方页没有作品日期的项目排在所有已知日期之后，不拿查阅日或模型上线日冒充作品日期。GPT-6.2 Astra 的官方型号是 gpt-6.2-astra，不写成 GPT-6 Astra、GPT-6.2 Sol，也不把 Astra Max 当成型号名。
